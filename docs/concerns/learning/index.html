勉強が心配なとき

学習の遅れや、取り組みにくい課題について相談するためのページです。

このページでは、相談で確認したいことと、関連する情報の入口をまとめています。状況によって必要な対応は異なります。

どの課題で困るかを整理する

教科名だけでなく、読む、書く、覚える、提出するなど、どこで負担を感じるかを整理します。できていることも一緒に伝えてください。

学校に確認すること

課題の優先順位、提出期限、使える教材、相談できる担当者を確認します。出席や評価については、学校の説明を聞いてください。

学び方について相談する

学びの場や教材を検討する際は、本人の希望と負担、利用条件を合わせて確認しましょう。診断名だけで学習方法を決めるものではありません。

相談機関の選択肢

地域によって利用できる窓口や対象が異なります。全国の窓口案内も使って、お住まいの地域から探せます。

  • 公的相談埼玉県総合教育センター （別タブ）

    教育相談を扱う公的機関。相談窓口・対象・申込方法を県の公式案内から確認できます。

  • 全国の窓口案内地域の不登校相談窓口（文部科学省） （別タブ）

    お住まいの地域の相談先を探すための公的な案内です。担当地域や利用条件は各窓口に確認できます。

  • 公的相談千葉県の教育相談窓口 （別タブ）

    子どもと親のサポートセンターや教育相談室などを案内しています。地域・相談内容に合う窓口を確認できます。

  • 公的相談東京都教育相談センター （別タブ）

    学校生活や高校の進級・進路・入学などの相談窓口。相談内容に応じた方法・対象を確認できます。
