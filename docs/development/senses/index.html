感覚の特性について知る

音や光などに関する困りごとの情報と相談先をご案内します。

このページでは、相談で確認したいことと、関連する情報の入口をまとめています。状況によって必要な対応は異なります。

感じ方には違いがある

発達に関する公的な資料では、感覚過敏や感覚鈍麻などの感覚の問題が紹介されています。感じ方や負担になる場面は一人ひとり異なります。

環境を具体的に伝える

負担になる音や光、安心できる場所、避けたい活動を具体的に伝え、学校や専門窓口と相談してください。感覚の困りごとだけで診断名を判断することはできません。
