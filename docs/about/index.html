センターについて

小学生・中学生・高校生の健全育成を目指して、教育問題に関する研究、情報共有、実践活動を行う教育機関です。

このポータルでできること

困りごとに関する情報や、相談方法への入口を探せます。センター以外の公的な窓口も含めて、今の状況に合う選択肢を確認するための情報をご案内します。
