# 子ども教育支援センター

小学生・中学生・高校生、保護者、小中高の先生向けの教育相談・教育支援ポータルです。

37ページで学校生活、学習、発達の特性、高校の転校・転学・退学、相談窓口、講師派遣などを案内します。

## 公開方法
GitHub Pages の Settings → Pages で Deploy from a branch、main、/docs を指定します。
公開用ファイルは docs に含まれています。予定するリポジトリ名は kodomo-education-support です。

## 更新
Node.js を使用して `node prepare-repo.cjs` を実行すると、src の内容から公開用 docs を更新できます。
画像は dist/assets の WebP を使用します。新しい画像を追加する場合もここに配置してください。

## 体験機能
教育支援ナビ・担当者ログイン・活動レポート投稿・相談予約は、APIを使わないブラウザー内の体験機能です。実際の認証、AI応答、投稿公開、予約受付、送信、永続保存は行いません。入力はページを閉じるか再読み込みすると消えます。

活動レポートの体験用IDは staff、パスワードは demo2026 です。実際の認証情報として使用するものではありません。

掲載写真はAI生成のイメージです。講師A氏・B氏の顔写真・紹介は架空の例です。診断や緊急対応は行いません。

外部窓口の対象・費用・受付条件は、それぞれの公式案内で確認してください。
